# Approved interface mockups

The [Explorer-first workbench](workspace-explorer-layout.html) is the approved version-one layout reference. It is a design artifact, not production code. Production implementation must preserve its information architecture and interaction hierarchy while meeting the accessibility, theme-token, responsive sizing, and native-platform requirements in the design specification.

The mockup establishes:

- LOOP24 default visual identity;
- Explorer/Nodes/Examples/Git/Settings activity rail;
- paired workflow tree and read-only resources;
- Visual/Split/YAML center modes;
- General/Execution/Advanced/Docs inspector;
- YAML/DAG/Git/update status bar; and
- the balance among workspace navigation, DAG canvas, and field editing.

# Keyboard shortcuts

Use this guide when you want to work faster without leaving the current Workflow Studio surface. The keyboard-help view is available from Documentation and from the **Keyboard shortcuts** command.

## Read the live help

The live shortcut table below comes from the application command registry and typed canvas interaction descriptors. It is generated from the commands and interactions that are actually registered, so labels, categories, contexts, platform key names, canvas gestures, and node-picker chords stay in sync with dispatch behavior.

## Platform key names

`Mod` means **Command** on macOS and **Control** on Windows and Linux. The live table displays the platform-specific key label; use the label shown for your computer.

## Know the scope

Canvas shortcuts apply only while the graph canvas has focus. Canvas single-key commands do not intercept typing in a form control or the YAML editor. The help also identifies interactions that are gestures or node-picker chords rather than executable commands.

## Fixed bindings in version one

Workflow Studio does not support shortcut rebinding in version one. If a command is unavailable in the current document state, its help entry still describes the registered binding and its context. Use the live table or the compact **Keyboard shortcuts** dialog for the current complete list.
